📊 Sistema de Base de Datos

🗄️ Gestión Centralizada

Hotel Nexora utiliza un sistema de base de datos relacional (MySQL) para almacenar y administrar toda la información operativa del hotel de forma segura y eficiente.

Este sistema permite mantener un control integral de reservas, huéspedes, habitaciones y transacciones financieras.
